One-time SQL setup

  1. Open your Supabase project → SQL Editor.
  2. Run supabase/rls_fix.sql (safe to re-run).
  3. Run supabase/db_all_pages_migration.sql (safe to re-run).
  4. Wait a few minutes for Supabase to refresh its schema cache, then reload the site.
